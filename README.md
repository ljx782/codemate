# CodeMate 求职工作台

面向应届生的多 Agent 求职全流程工作台，基于阿里云百炼通义千问系列模型。打开网页、零配置、无需 API Key 即可体验全部 AI 功能。

## 五大 Agent

1. **人岗匹配** — JD 与简历五维评分、差距诊断、匹配分提升曲线
2. **JD 解析** — 岗位关键词与技能要求结构化拆解
3. **简历精修** — 事实接地机制：先摘录简历事实再改写，每条优化可溯源，AI 不编造经历
4. **语音模拟面试** — Qwen3.5-Omni 全模态模型，张嘴作答、语音追问、自动复盘
5. **投递台账** — Function Calling 自动安排面试日程、生成导航与日历文件，逾期自动预警，一键导出求职冲刺 PPT / 复盘报告

## 技术实现

- 原生 HTML/CSS/JavaScript 零构建，极简 Node.js 服务（仅内置模块）
- 服务端同源代理 `/api/qwen`：模型白名单 + token 上限，访问者无需填 Key
- 数据全程浏览器本地存储，适配桌面与移动端
